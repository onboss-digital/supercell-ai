A detailed Ads Analysis page for SuperCell AI. It should focus on Facebook Ads performance metrics.

**DESIGN SYSTEM (REQUIRED):**
[DESIGN SYSTEM: "The Digital Curator". Colors: Primary #0049db, Secondary #10B981 (Emerald), Tertiary #C5A059 (Gold). Surface: #f8f9ff. Rules: 1. NO solid borders (use tonal shifts). 2. Glassmorphism for floating UI. 3. Massive Display typography for metrics. 4. Roundness: 1rem (xl) for cards, 0.5rem (md) for buttons. 5. Spacing Scale: Base 4px, standard gaps 32px (8).]

**Page Structure:**
1. Header with title "Análise de Anúncios" and date picker.
2. Top Metrics Bar: Total Spend, CPA, CTR, ROAS.
3. Performance Chart: Line chart showing daily spend vs leads.
4. Ad Table: Listing active campaigns with status, budget, and key KPIs.
5. AI Summary: A glassmorphic card with Jarvis's take on the current ad fatigue or scaling opportunities.

**Layout Mandate:** Use the "No-Line" rule. Separate sections using `surface-container-low` background shifts.
